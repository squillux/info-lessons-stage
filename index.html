  • 수업 전에 전체를 보려면 활동 페이지 오른쪽 위 ☰ 펼치기, 다시 누르면 접기예요.
  • 전자칠판에서는 가+ 크게와 전체 화면을 쓰세요. 인쇄하면 모든 활동이 펼쳐져 학습지처럼 나와요.
  • 단원별 주소를 나눠 줄 수 있어요. 예: 이 페이지 주소 끝의 ?unit=2
  • 수업 모드: ⏱ 압축(소단원마다 종합 수업 + 🎯 대표 활동 1개), 📘 기본(종합 수업 + ★ 핵심 활동), 🌱 전체(☆ 선택 활동까지). 태그를 누르면 토의·엔트리 실습처럼 원하는 종류만 골라 볼 수 있어요(여러 개 선택 가능). 카드 아래 [9정○○-○○]은 관련 성취기준이에요.
  • 학생 로그인을 켜면 학생은 학번과 개인 코드로 로그인하고, 선생님이 연 활동만 할 수 있어요. 활동 진도·퀴즈 결과·접속·출석 기록은 👩‍🏫 교사용 관리 화면에서 봐요. 활동 속에 적은 답은 저장하지 않아요. 📡 실시간 활동은 이름 없이 투표 수와 제출 내용을 서버에 보관하며, 선생님이 결과 내려받기 후 기록 지우기를 할 수 있고 30일이 지나면 자동으로 지워져요. 심화는 교과서 밖 내용, 더 해 보기는 선택 활동이에요.
  • 📡 실시간 표시 활동은 반 전체가 함께 투표하거나 응답을 모을 수 있어요. 👩‍🏫 교사용 관리 화면의 📡 실시간 활동에서 [▶ 실행]을 누르면 방 코드와 QR 코드가 나오고, 학생은 활동 화면에서 코드를 입력하거나 QR을 찍어 참여해요. 서버에는 이름 없이 투표 수와 제출 내용만 남고, 부적절한 제출물은 선생님이 숨길 수 있어요.
